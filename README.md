# Mini NPU Simulator

## 1. 프로젝트 소개

이 프로젝트는 작은 NPU(Neural Processing Unit)의 연산 방식을 흉내 내는 Python 기반 콘솔 프로그램이다.

두 개의 필터(Cross, X)와 입력 패턴 사이의 MAC(Multiply-Accumulate) 연산 점수를 계산하고, 점수를 비교하여 입력 패턴을 판별한다.

## 2. 개발 환경

- Python 3.11.6
- Visual Studio Code
- 외부 라이브러리 사용 없음
- Python 표준 라이브러리 사용

사용한 모듈:
- `json`: JSON 데이터 읽기
- `re`: 패턴 ID에서 행렬 크기 추출
- `time`: 연산 시간 측정
- `math`: 숫자의 유효성 확인
- `pathlib`: 데이터 파일 경로 처리

## 3. 파일 구성

```text
Mini_NPU/
├── main.py
├── data.json
└── README.md
```

- `main.py`: 프로그램 실행 및 연산 로직
- `data.json`: 필터와 테스트 패턴 데이터
- `README.md`: 프로젝트 설명 및 테스트 결과

## 4. 실행 방법

프로젝트 폴더에서 다음 명령어를 실행한다.

```bash
python main.py
```

실행 메뉴:

1. 사용자 입력 모드
2. JSON 분석 모드
0. 종료

### 사용자 입력 모드

- 3×3 필터 A와 B를 입력한다.
- 3×3 입력 패턴을 입력한다.
- 각 필터와 패턴의 MAC 점수를 계산한다.
- 두 점수를 비교하여 A 또는 B를 판정한다.
- 연산 시간과 성능 분석 결과를 출력한다.

### JSON 분석 모드

- `data.json` 파일을 읽는다.
- 5×5, 13×13, 25×25 패턴을 분석한다.
- 각 패턴에 적합한 크기의 필터를 선택한다.
- 계산 결과와 정답을 비교하여 PASS 또는 FAIL을 출력한다.
- 전체 테스트 결과와 크기별 성능을 출력한다.

## 5. 핵심 구현 내용

### MAC 연산

행렬의 같은 위치에 있는 값을 곱한 뒤 모든 결과를 더한다.

```python
def mac(input_matrix, filter_matrix):
    score = 0

    for i in range(len(input_matrix)):
        for j in range(len(input_matrix)):
            score += input_matrix[i][j] * filter_matrix[i][j]

    return score
```

외부 라이브러리 없이 중첩 반복문을 사용하여 MAC 연산을 구현했다.

### 판정 로직

- Cross 점수가 더 크면 Cross로 판정한다.
- X 점수가 더 크면 X로 판정한다.
- 두 점수의 차이가 EPSILON보다 작으면 UNDECIDED로 판정한다.

```python
EPSILON = 1e-9
```

부동소수점 연산에서 발생할 수 있는 미세한 오차를 고려하기 위해 허용 오차를 적용했다.

### 라벨 정규화

JSON 데이터의 정답 표기를 프로그램 내부의 표준 라벨로 변환한다.

| 입력 표기 | 변환 결과 |
|---|---|
| `+` | Cross |
| `cross` | Cross |
| `x` | X |

### JSON 데이터 처리

- 패턴 ID에서 정규표현식으로 행렬 크기를 추출한다.
- 추출한 크기에 맞는 필터를 선택한다.
- 행렬의 크기와 숫자 형식을 검증한다.
- 잘못된 데이터가 있으면 해당 케이스를 FAIL 처리하고 다음 케이스를 계속 분석한다.

## 8. 시간 복잡도 분석

MAC 연산은 행렬의 모든 원소를 한 번씩 확인한다.

N×N 행렬을 기준으로 계산하면 총 연산 횟수는 다음과 같다.

```text
N × N = N²
```

따라서 시간 복잡도는 O(N²)이다.

| 행렬 크기 | 연산 횟수 |
|---|---:|
| 3×3 | 9 |
| 5×5 | 25 |
| 13×13 | 169 |
| 25×25 | 625 |

행렬 크기가 커질수록 연산 횟수가 제곱에 비례하여 증가하는 것을 확인할 수 있다.

## 9. 오류 및 예외 처리

프로그램의 안정성을 위해 다음 항목을 검증했다.

1. 입력 행렬의 행과 열 개수가 맞지 않는 경우
2. 숫자가 아닌 값이 입력된 경우
3. 행렬 크기가 필터와 일치하지 않는 경우
4. JSON 파일이 존재하지 않는 경우
5. JSON 데이터 형식이 잘못된 경우
6. 필수 필터 또는 패턴 데이터가 누락된 경우
7. 유효하지 않은 숫자 값이 포함된 경우
8. 잘못된 사용자 입력에 대해 재입력을 요청하는 경우
9. 특정 테스트 케이스에서 오류가 발생해도 나머지 케이스를 계속 분석하는 경우
10. 점수가 같거나 허용 오차 이내인 경우 UNDECIDED로 판정하는 경우
